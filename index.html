ROB MESH

One person, several machines, one AI harness on each — and git as the wire between them. No server in the middle.

What it is

Each machine runs an AI harness agent. The agents can't see each other and there is no central server, so shared state lives in git: git pull is "check my inbox", git push is "send". The orchestrator plans and dispatches; the nodes execute — a job is placed in a machine's queue, its loop picks it up, runs it, and pushes the result back. A job isn't real until it's pushed.

Minimum to run it

To join as a node: any machine with git and a route to the hub (Tailscale or GitHub) — a spare laptop or a Pi will do. To run an agent on it, add Node.js + an AI harness. To build, add the matching toolchain (Rust for Rust work, Linux for Linux builds). MorpheOS itself starts at a Pi Zero 2 W.

Agent fan-out

One parent session fans out to up to 6 concurrent child agents, nesting to depth 3. A fully-expanded tree is 1 → 6 → 36 → 216 = 259 agents from a single instruction (workflow cap 1000) — bounded by model tokens and rate limits, not CPU.

What that lets us do: one "go" fans out across every machine and every file at once — a repo audit that reads each module in parallel, a multi-angle research sprint that compares independent agents' notes, a cross-OS build/verify matrix dispatched across the nodes. The mesh runs a tree of work, then folds the results back up.
