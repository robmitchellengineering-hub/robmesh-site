AirMatrix — today

Wireless-first, broadcast-grade audio over IP

Broadcast-grade, low-latency, synced 24-bit audio over the Wi-Fi you already own — with an any-to-any matrix, a live mixer, comms, recording and show control. It has been measured over real Wi-Fi (E1, E15, the stream-clock A/B), the stream clock is the downlink default, two radios grade Programme/Monitor, and comms is field-tested — phone to laptop, both ways.

This page is the whole suite in one read — what is measured, what is real, and what is still honestly not built. Phase 0 is done; Phase 1 (one link in grade) is nearly closed.

The boundary that matters: "measured" over real Wi-Fi means E1, E15 and the stream-clock A/B; comms is field-tested on the Legion. The desk, engine, processing, metering, recorder, show control and AES67 are "built and tested in software" (simulation + loopback). Say which one you mean — never "works" — until a person has run it on the gear it is for.

Where it's going

Phase 0 is done and Phase 1 (one link in grade) is nearly closed — the field numbers already moved the design: the stream clock became the downlink default, and two radios grade Programme. What is left is the last gate (the 3-run repeat and N2 independence), then Phase 2 (a 4-node show with the backup engine), Phase 3 (a real Dante/AES67 box and Blackmagic interop), Phase 4 (comms and tally across the show — mostly built already) and Phase 5 (the hardware nodes).
